# Weekify («Викифай»), a tutor CRM: public facts checked on 2026-11-23

Checked 2026-11-23 by an agent from public sources only: no sign-in, no account, no form submitted. Product features, prices and terms are volatile; recheck them before relying on them. This file is agent research: it supplies evidence for the [Weekify gap map](../analysis/weekify-gap-map-2026-11-23.md) and [proposal 0007](../../docs/proposals/0007-tutor-crm-scope.md) and decides nothing. It supersedes the Weekify section of the [research of 2026-10-25](tutor-crm-and-mobile-distribution-2026-10-25.md) where they differ (the trial is now 30 days). The project owner names Weekify as the product OVC should match, so it is named here. The developer is a private individual; their name and tax number are in the cited offer and are left out of this file. "FP" means first-party (Weekify's own site, legal PDFs, store listing text written by the developer, or the public client code its site serves). "TP" means third-party (catalogues, store reviews, store metadata). Source numbers refer to the list at the end.

## 0. Name disambiguation

- **Weekify / «Викифай»** at `weekify.ru` is the tutor CRM. The page title reads "Викифай - CRM для репетитора" [1]. The RuStore package is `ru.weekify.weekify` [5].
- **vikifi.com** is an unrelated online-store builder with a 5-day trial [12, TP-ish, checked only as a disambiguation]. `vikifi.ru` and `vikify.ru` do not resolve (DNS ENOTFOUND, 2026-11-23).
- Earlier web searches for "Vikifi" found nothing relevant. The correct spelling is Weekify.

## How the evidence was gathered and how much to trust it

- `weekify.ru` is a client-rendered Nuxt single-page app. The HTML has no content beyond the title and meta description [1]. Most first-party feature detail below comes from two places:
  - the landing page's built-in FAQ assistant ("Чат с ассистентом Викифай"). Its question-and-answer entries ship in the public JS bundle and are refreshed from `api.weekify.ru/api/landing/chat` [2];
  - UI strings and API route names in that same public bundle [2]. The bundle contains the tutor workspace itself.
- The research read the bundle text but called **no API endpoints**. Route names (for example `/finances/upload_receipt`) show that a capability exists in the client. They are not documentation. Treat items marked "(bundle)" as medium confidence.
- `robots.txt` reads `Disallow: /` and `Allow: /$` [3], which asks crawlers to stay off everything except the home page. The research did not crawl, but it did fetch, one by one, files that rule covers: the three legal PDFs (the App Store links one of them) and the JS assets the home page loads, as a browser opening the home page would. A later recheck should weigh this against the robots rule.
- the research found **no public help centre, knowledge base or documentation site**. `/help`, `/faq`, `/docs`, `/api/docs` and `/swagger` all return the SPA shell, and the sitemap lists only `/` [3]. Support runs through the VK group `vk.com/weekify` and `support@weekify.ru` [2][4][5].

## 1. What it is, audience, pricing, platforms

- **What it is:** a workspace for a single private tutor. The offer defines two roles only: a tutor's cabinet or a student's cabinet [4]. the research found no school, multi-teacher, admin or salary mode anywhere [2][4].
- **Pricing (FP, current):** first 30 days free, then **350 ₽ per 30 days**. All features are included and there are no tiers. No card is needed and there is no auto-renewal: the user extends access manually [2]. This conflicts with the repository note of 2026-10-25, which records a 14-day trial; the current landing FAQ says 30 days.
- **Referral promo code (FP, bundle):** a friend who enters your promo code gets a doubled trial. If the friend then pays, you get one bonus month [2].
- **Pricing (TP):** the picktech.ru catalogue lists "от 250 руб. в месяц", card updated 2026-10-05 [11]. This is probably stale.
- **Platforms:**
  - web app at `weekify.ru`, with a separate student and parent web cabinet at `student.weekify.ru` [2];
  - iOS app «Викифай», iPhone only, iOS 17.6+, version 1.0.21 [6];
  - Android app on RuStore, version 1.0.20 (2026-11-03), Android 7+, up to 1,000 downloads [5];
  - a direct APK at `storage.weekify.ru/weekify.apk` [2];
  - a separate student and parent mobile app, reached from `student.weekify.ru/mobile` [2].
- **Telegram:** used for notifications and password-less login confirmation [2]. the research found no evidence of a Telegram bot that does CRM work. Not confirmed.
- **Developer:** a private individual named in the offer, whose 12-digit individual tax number indicates a natural person or sole trader rather than a company [4][7].

## 3. Export, import, API, integrations

- **Export:** **nothing found.** The bundle has no Excel, XLSX, CSV, PDF, iCal, "экспорт" or "выгрузка" strings and no export route among the roughly 150 API routes [2]. The only "Скачать" actions are the QR code and the mobile app. Store listings and the catalogue do not mention export either [5][6][11]. Conclusion: no user-facing data export is visible publicly. Not confirmed from inside the product.
- **Import:** no file import (Excel or other CRM). The only bulk feature is pasting a list of student names [2].
- **Public API / webhooks:** none documented. There is a private JSON API at `api.weekify.ru/api`, used by the web app. Its CORS allows only `https://weekify.ru`, and `/api` itself returns 404 [one HEAD request to that host, 2026-11-23]. the research found no API keys, webhook settings or developer docs.
- **Integrations:**
  - VK, Telegram and MAX accounts, linked for notifications and login [2];
  - WhatsApp, Telegram and MAX as contact links only [2];
  - sharing to Telegram and VK [2];
  - Yandex.Metrica on the site [8].
  
  Not found: Google Calendar, amoCRM, Bitrix24, payment acquiring, «Мой налог».

## 4. Terms, privacy policy and offer

### Documents

- Offer «Условия использования сайта weekify.ru (Оферта)», published 01.11.2025 [4].
- Privacy policy, an undated PDF [7].
- Cookie notice [8].

All three are PDFs at the site root. Their text was extracted with macOS PDFKit on 2026-11-23.

### Operator

- The offer names the developer, a private individual, as the operator and site owner [4].
- The privacy policy calls him «Оператор» under 152-FZ [7].
- **The policy covers only "site users".** It lists the user's name, email and VK/Telegram/MAX IDs, plus technical data such as IP, cookies and browsing history [7].
- **The policy does not mention the students' and parents' data that tutors enter**, and the research found no data-processing assignment (поручение, art. 6(3) 152-FZ) in any public document.
- Instead, offer §7.5 makes the tutor warrant that they have the consents of the people whose data they pass to the operator, and indemnify the operator against claims [4].

So the operator presents itself as an operator for its own users and is silent on its role for the data inside tutor workspaces. This is an inference from what the documents omit.

### Data ownership

- §5 ("Интеллектуальная собственность") vests all rights to "Объекты Сервиса" in the operator, including information, texts, images and structure [4].
- The offer has **no clause on who owns user-entered content** and **no data export or portability clause** [4].

### Scraping, reverse engineering, automated access

- §4.1.7 obliges users not to circumvent technical copyright protection measures [4].
- §4.6 bans disrupting the site and uploading code meant to break it or to gain unauthorised access [4].
- §5.3 bans any use of service objects beyond the offer without written permission, including "воспроизведение, копирование, модификация, переработка" [4].
- There is **no explicit clause on scraping, bots or automated access**. `robots.txt` disallows all crawling except `/` [3].

### Account closure and deletion

- The user may terminate at any time (§4.2.1) [4].
- On a free plan, termination after disagreeing with offer changes takes effect 3 business days after notice. On a paid plan it takes effect at the end of the paid period (§6.3) [4].
- The operator may block or delete an account for breach (§4.5.4) [4], and may terminate without notice or compensation, including if the service shuts down (§6.6) [4].
- The offer says nothing about what happens to data on closure.
- The policy says data is destroyed within 30 days after the purpose is reached or consent is withdrawn, the latter by email to `support@weekify.ru` (§§5.6, 6.4–6.5) [7]. Requests are answered within 30 calendar days (§6.8) [7].

### Data safety

- The service is provided "as is" (§7.1) [4].
- The operator does not guarantee "сохранность информации" except as the privacy policy requires (§7.2(б)) [4].
- Liability is capped at the fees paid over the last 12 months (§8.3) [4].

### Storage location

- The policy says the operator does not carry out cross-border transfer (§5.9) [7].
- It does not name a data centre.
- `weekify.ru`, `api.weekify.ru` and `storage.weekify.ru` all resolve to 46.8.197.46. ipinfo.io places that address in Novosibirsk, Russia, on AS57494 (Adman LLC) [a DNS lookup plus ipinfo, 2026-11-23]. This points to hosting in Russia. It is not proof of where the database sits.

### Other terms

- Russian law applies. Disputes go through a 10-business-day claim procedure, then to court at the operator's location (§9.2) [4].
- The operator may send advertising to users' contacts, and registering counts as acknowledging this (§4.8) [4].
- The operator may change the offer unilaterally, with effect from the day after it is published (§6.2) [4].
- The cookie notice covers retargeting and Yandex.Metrica [8].
- The App Store privacy label claims "no data collected" [6], which conflicts with the policy's list of collected data [7].

## 5. Public reviews (TP)

- **RuStore:** 4.7 from 12 ratings, 4 written reviews (2024-11 to 2026-05), all positive [5]. Users praise the full-week view, payment balances, the shareable schedule link and reminders. One user asks for a single list of all lessons with their topics.
- **App Store (Georgia storefront):** 1.0 from a single rating [6]. The reviewer complains that support is VK-only, that the service went from free to paid without improvements, and that the app is worse than the site. The developer replied.
- **picktech.ru:** catalogue card, no reviews, "от 250 руб." [11].
- the research found nothing on otzovik, crmindex, startpack or a2is [10].

## 6. Gaps and confidence

- **High confidence** (first-party text): pricing and trial, notification types and channels, the student and parent cabinet, balances, the deposits and credits model, schedule mechanics, and the legal terms.
- **Medium confidence** (bundle route names and UI strings): parents marking payments, receipt uploads, the task tracker, the link shortener, and the absence of export, import, calendar sync and homework attachments. A feature could sit behind a server-side flag or in a separate chunk that was not loaded. The entry chunk and its 57 direct imports were loaded.
- **Not confirmed:** the payment provider for subscriptions; whether email or push notifications exist in the mobile apps; whether data deletion on account closure is automatic; and anything visible only after sign-in.
- **Not found:** a help centre, a public API, webhooks, school or multi-teacher mode, fiscal receipts, and online acquiring for students.
