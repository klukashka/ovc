# Local S3-compatible storage for development and tests

Checked 2026-10-21. Facts here are volatile; recheck them before relying on them after this date.

## Requirement

Local development and integration tests need an S3-compatible server in Docker Compose that supports what OVC's [files specification](../specs/files.md) and the threat model's T-35 control rely on: SigV4 presigned `PUT` and `GET`, the `response-content-disposition` override on presigned `GET`, multipart upload, bucket CORS, and private buckets by default. It must start as one container, be maintained, and carry an acceptable licence. Production uses a Russian provider's S3 service ([ADR-0008](../../docs/decisions/0008-hosting-and-data-residency.md)); the local server only has to behave like S3 for these operations.

## Probe

SeaweedFS 4.48 (`chrislusf/seaweedfs:4.48`, digest `sha256:4e61d15fd35994cb1e43e1e553dff106794841fd9a99ade2fc8c8bfce4d7872d`) was started with `server -s3` and access keys from `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`, and exercised with the AWS SDK for Go v2 (path-style addressing). Every check passed:

- an anonymous `ListBuckets` and an anonymous object `GET` are refused with 403, so buckets are private by default;
- a presigned `PUT` with `Content-Type` uploads, and a presigned `GET` returns the body;
- a presigned `GET` with `response-content-disposition` set to `attachment` with an RFC 6266 UTF-8 file name returns that header unchanged;
- an expired presigned `GET` is refused with 403;
- a bucket CORS rule admits the configured origin on preflight and gives no `Access-Control-Allow-Origin` to another origin;
- a two-part multipart upload (5 MiB plus 4 bytes) completes with the right size.

## Decision

SeaweedFS 4.48, pinned by digest in `docker-compose.yml` and recorded in the [stack table](../architecture/detailed.md#stack-per-component). PostgreSQL 18.6 (`postgres:18.6`, digest `sha256:74935e72241653ca55e0414067e6d8763aceb8a810eb51b452253ec3dcfc4336`) is the current major release and is pinned the same way.
