# Slice 7 L2b: shared local meeting provider

Status: approved by the owner on 2026-11-05 against main 48c9fad7beab9867cf64765612fd46cfb2b38045. L2a merged with an ordinary full gate and finish. This is local development without a BBB host.

## Problem, scope and outcome

The L1 in-memory fake cannot share rooms between API and worker processes. Add a PostgreSQL-backed implementation of the same Provider interface, with its own bounded infrastructure state, independently tested through two clients and a child process. It is not the business meetings repository and cannot authorize an application user. Existing L1 behavior remains unchanged.

No API routes, browser room, process wiring, new settings, external HTTP service, callbacks, BBB adapter or media are introduced. Authorized join/end flows, activation-time purge/reconciliation and browser room remain subsequent approved stages. The eventual HTTP test-room surface is not replaced by a database API exposed to clients. No procurement or remote credentials are needed.

## Design and contracts

Add SharedFake in internal/adapters/meeting using the existing pgx dependency. Its constructor receives a caller-owned pool, Clock, random source, logger and FakeLimits. It owns no pool lifetime or background goroutines. Database tables have a fake_meeting_ prefix and no foreign keys to business meetings, lessons or users. This follows the existing infrastructure-adapter exception to repository-only business database access. Update the architecture map explicitly.

Migration 00023 (verify availability) creates singleton provider state, rooms, participants and issued-link records. The singleton stores an opaque 256-bit namespace generated through injected randomness at first initialization, immutable configured limits, monotonic create-time/link-sequence/generation counters, and explicit simulated-unavailable state. Initialization is transactional and concurrent constructors converge on one namespace and identical limits; mismatched limits fail explicitly without changing existing state. Reject limits exceeding the signed bigint representable range. Namespace initialization requires fresh cryptographic randomness in eventual application construction; tests inject deterministic independent namespaces. Namespace is not a secret or authorization substitute. Collision resistance depends on secure randomness; two cloned databases are not independent provider namespaces. No claim of isolation for identical cloned state/entropy is made.

All mutations serialize on that database's provider-state row, using a consistent state -> room -> participant/link order. Global room/link/generation bounds apply across instances, not separately per process. Per-room distinct participants remain bound to roles until End, as in L1. Counters and checked arithmetic prevent overflow. Indexed exact lookups avoid unbounded scans; FK cascades remove room-owned participants/links. No eviction, retries, unbounded pending queue or background cleanup. Capacity refusal is explicit; End releases active room/link/participant state, retaining only singleton scalar counters. Active state without End remains bounded but retained; application activation must add lifecycle cleanup/reconciliation before rooms can be created by users.

Create/Info/JoinLink/End preserve the existing generation-bound provider contract. Create idempotency uses the same active ID/name semantics. Synthetic create time advances monotonically across reconstruction and process restarts, even when the injected clock is unchanged. End removes only its expected generation and revokes all its links; stale operations cannot affect a replacement room. Database constraints enforce nonzero IDs, valid roles/states and positive create time/counters with explicit NULL handling.

Shared fake links are redacted JoinLink values with a separate synthetic scheme, never navigable HTTP addresses. They contain the persisted namespace, a monotonic sequence and a 256-bit random token. Store only a SHA-256 digest of the complete capability plus its room generation, participant ID and role, never the raw token/address. Validate exact canonical syntax and bounded length before lookup. SharedFake.Enter may import a revealed shared-fake address through NewJoinLink so a second process can redeem it; this is an explicit shared-fake contract difference from L1's private issuer marker. L1 keeps rejecting reconstructed and foreign-instance capabilities. Namespace mismatch, modified/unknown token, wrong participant/role/generation and ended credentials refuse without mutation. Repeated Enter does not increment duplicate participant connections. Participant display names are validated but not persisted; active room names are bounded by the existing lesson-title limit and removed on End. The fake capability cannot sign anyone into OVC and is never sent to the current frontend.

Clock reads and random generation occur before acquiring transaction locks, preventing a shared-clock pool dependency deadlock. Resource errors are applied only to operations that actually need a new value after inspecting the locked state: an already existing identical Create stays idempotent when the clock is failing. Initialization of an already existing provider likewise does not require new namespace entropy. A private per-client synchronization guard protects the injected io.Reader from concurrent calls; no database lock is held while acquiring that guard or reading entropy. No goroutine is created to interrupt a blocked reader. An injected non-concurrency-safe reader is exclusively owned by one client; sharing a reader across clients is permitted only when the caller supplies a concurrency-safe implementation. Tests give clients distinct deterministic readers, while concurrent calls on one client prove the internal guard. The caller's context bounds database acquisition/waits/operations; check cancellation before publishing. Do not hold database locks while reading injected entropy or calling Clock. Do not promise that arbitrary io.Reader blocks can be interrupted. All errors are returned as safe typed provider failures, including a database failure category, without raw SQL values or connection strings. Cancellation/rollback before commit leaves no change. A failed commit can have an uncertain outcome: do not claim rollback or retry automatically. Idempotent Create/End and Info permit later reconciliation; an uncertain JoinLink can retain an unreturned bounded slot until End. This limitation must be explicit before application activation.

Preserve the fixed provider diagnostics (operation/outcome or safe failure kind); cancellation remains non-warning. No room IDs, participant IDs/names, link digests, raw tokens, addresses, DB credentials or raw database errors enter logs. No business lifecycle event is fabricated by the adapter.

## Checkable acceptance criteria

- TestSharedFakeProviderContract: the reusable Provider contract passes against PostgreSQL as well as the existing in-memory fake. Existing L1 capability rejection tests still pass unchanged in meaning.
- TestSharedFakeAcrossProcesses: parent creates a room/link; a separate child Go process observes it, enters with the issued credential, and parent observes presence; End in the parent causes child rejection of the old link. Assertions compare exact IDs/create times/status/counts, not merely successful calls. Child failure cannot leak credentials or leave a live process.
- TestSharedFakeInitializationAndLimits: two independent pools race initialization, require identical configuration, enforce exact global room/link/generation and per-room participant bounds, reject mismatches and signed-counter exhaustion without changes. Use real observed locks/barriers, not sleeps.
- TestSharedFakeGenerationAndRevocation: independent clients reconstruct state and share monotonic create times; old handles/links cannot affect replacement rooms; wrong namespace/participant/role/token refuses; repeated Enter/Leave retains role binding; End releases all room-owned state.
- TestSharedFakeCancellationAndResources: cancel an observed real PostgreSQL lock wait and prove no mutation; cancelled operations release transactions/connections; a one-connection pool with a real shared clock does not deadlock; errors from clock/random leave state unchanged when new values are required; an identical existing Create succeeds even with a failing clock. Concurrent JoinLink calls on one client with an ordinary non-thread-safe deterministic reader pass under -race. Do not simulate uncertain commit using forbidden transport interception.
- TestSharedFakePrivacyAndStorage: query actual stored rows to prove raw tokens/addresses and participant names are absent; test all existing Secret formatting/logging encodings and safe database-error diagnostics. Independent fixture namespaces reject each other's capabilities. No authorization equivalence with business meetings is asserted.
- TestSharedFakeMigrationRoundTrip: disposable database migration 22 -> 23 -> 22 -> 23 preserves pre-existing business rows; rollback only removes new infrastructure tables. No owner/development database is migrated by the agent.
- Real races and provider contract tests pass with -race; architecture/conventions and full backend remain passing. Production entry points remain unwired and no new HTTP surface or environment setting exists.
