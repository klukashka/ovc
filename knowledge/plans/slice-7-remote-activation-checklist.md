# Slice 7 remote-activation checklist

Status: recorded 2026-11-07 from the [slice 7 slice review](../reviews/slice-7-slice-review.md); an inventory of items to prove or decide before a real BigBlueButton provider is selected, not an approved probe protocol. It adds to the probe requirements of the [slice 7 plan](slice-7.md#remote-prerequisites-and-probe-before-live-provider-acceptance) and does not replace them. No remote host exists and nothing here is authorized to run; the bounded probe protocol, its thresholds and its approval come first. Every item stays `unverified` until measured on the remote host, and an unmet item blocks activation unless the owner accepts it explicitly.

## Items

| Item | Why it matters | Evidence needed before activation |
| --- | --- | --- |
| End latency against the 5-second End wait | The adapter confirms End only when 5 reads one second apart observe the meeting absent. A provider whose asynchronous end takes longer makes restart answer `503` on a healthy host until the next tutor join, and keeps the restart-blocks-the-room residual of the [known limitations](../reviews/slice-7-known-limitations.md#meeting-lifecycle-residuals) open longer. | Measured end-to-absence latency over a fixed sample on the probe host, compared with the 5-second confirmation window; a decision to keep or change the window if any sample exceeds it. |
| The quiet-window premise behind proxies | The quiet-window settlement of [ADR-0021](../../docs/decisions/0021-quiet-window-meeting-settlement.md) assumes no dispatched Create is replayed. OVC's transport never replays, but `create` is a GET and a reverse proxy or load balancer may retry it, creating a room OVC records as absent or ended. | The deployed path to the provider API has a single upstream and no retry or replay of API requests (for nginx, `proxy_next_upstream off` for the API path), confirmed from the configuration and by a probe request that fails upstream once; the ADR-0021 premise names the condition. |
| Admission caps against host capacity | 64 unsettled obligations per tutor and 4096 overall are far above what one self-hosted host carries, so a few self-registered accounts could exhaust it. | Host capacity measured by the probe, and a deployment-level open-room cap or a tighter per-tutor open-room count derived from it, decided before activation. |
| A limit on the ended-hint route | The unauthenticated hint route shares 4 process-wide permits and has no per-client limit, so floods can decline genuine hints once a provider is active. | A per-address limit on the route, or a reverse proxy rule that admits it only from the conferencing host, implemented and tested; the T-12 residual updated. |
| A visible signal for declined hints | A declined hint is logged only at DEBUG as `meeting.hint.declined` (`backend/internal/services/meetings/lifecycle.go`), so a flood of anonymous hints would not show at the production INFO level. | Declined hints reported at INFO or counted in a signal operators see, implemented and tested before activation. |
| iPhone Safari new-tab behaviour | On phones every join opens a blank tab and navigates it when the join answer arrives; with the opener in the background, WebKit may delay that navigation and leave the student on a blank page. | A slow join on a real iPhone with the opener backgrounded, observed to reach the room; if it fails, a same-origin OVC joining route that performs the join in the new tab. Playwright WebKit is not a substitute. |
| Frame redirects losing camera permissions | The frame's `allow` list applies only to the frame's own origin; a join address that redirects to another origin loses camera and microphone, and the page cannot detect it. | The redirect chain of a real join address recorded; if it leaves the room origin, that origin added to `allow` and `frame-src` and the embedding decision updated. The decision on a `Permissions-Policy` header and a frame sandbox is recorded in T-16 at the same time. |
| Cleanup unchanged-generation and revocation-conflict branches | The cleanup branch for an unchanged generation after a refused End, and the revocation `conflict` branch, are unreachable with the shared fake and, by reading, with the adapter; they become reachable only if the identifier is re-created outside OVC or by an intermediary replay. | Remote contract evidence that End and inspection behave as the adapter assumes, the no-replay condition above confirmed, and either a test that reaches each branch against the real protocol or an explicit owner acceptance that they stay unreachable ([known limitations](../reviews/slice-7-known-limitations.md#cleanup-reinspection-interleaving)). |
| Real-network reconnect measurement | A hung WebSocket handshake can delay the next socket until the browser gives up, and the browser's own timeout was not measured ([known limitations](../reviews/slice-7-known-limitations.md#realtime-client-connection-limits)). | Reconnect time over a real network in the supported browsers, including the stalled-upgrade case, with a decision on a client connect deadline. |
